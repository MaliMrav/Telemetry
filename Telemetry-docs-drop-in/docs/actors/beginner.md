# Actor — The Beginner

Telemetry should be understandable to somebody who has not already learned the vocabulary of embedded architecture.

## The Beginner's Need

The beginner needs to see why a boundary exists before being asked to implement it.

They should be able to trace a value through the system and understand why each layer has a responsibility.

## A Useful Learning Path

```text
Physical world
    ↓
Source
    ↓
Observation
    ↓
Repository
    ↓
Composition
    ↓
Screen
    ↓
Human understanding
```

The code is evidence of these ideas.

## The Important Lesson

A beginner should leave Telemetry knowing not only how to build a small device, but how to recognise the moment when a prototype is becoming a system that needs architecture.
