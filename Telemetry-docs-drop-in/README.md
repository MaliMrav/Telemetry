# Telemetry Documentation Drop-In

This package adds the new philosophy, actor and learning documentation layers and extends the existing architecture history with Architecture 009 — Energy Composition Proving Slice.

It is intentionally additive.

Existing architecture documents 001–008 remain the authoritative history and are not replaced by this package. Existing roadmap content is also untouched.
