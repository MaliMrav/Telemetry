# Actor — The Maintainer

The maintainer inherits decisions without necessarily inheriting the circumstances that created them.

## The Maintainer's Question

> “Why is this boundary here?”

A maintainer may see an extra layer, a generated definition, a seemingly indirect lookup or a capability that is not used by the current target.

Without history, simplification can accidentally recreate old coupling.

## What the Documentation Must Preserve

For significant decisions, record:

- pressure;
- affected actors;
- alternatives;
- evidence;
- decision;
- capability gained;
- new pressure created.

## The Goal

Maintenance should be an act of understanding rather than archaeology.
